# ISO200での色補償・ガンマ・逆LUT実機比較（2026-07-30）

## 結論

Avを前回の基準値14から変えず、**ISO200・Av14・1/15秒**で、露出確認、
逆LUT測定、3方式の64色校正、4条件12枚の実写比較をすべて実行した。

ISO160版より撮影結果は明るくなり、今回の最良方式は解析ガンマ2.2だった。

| 条件（3画像平均） | PSNR [dB] | SSIM | Delta E76 |
| --- | ---: | ---: | ---: |
| 色補償なし | 14.56 | 0.402 | 27.54 |
| 色補償あり・ガンマ補正なし | 16.60 | 0.4050 | 19.10 |
| **色補償あり・解析ガンマ2.2** | **17.48** | **0.4057** | **16.86** |
| 色補償あり・実測逆LUT | 17.19 | 0.3980 | 19.41 |

ISO160の解析ガンマ版に対し、ISO200ではPSNRが0.76 dB向上し、
Delta E76が0.97低下した。平均sRGB輝度は0.3846から0.4013へ約4.3%上昇した。

## 撮影条件

- カメラ: Canon EDSDK、フル解像度RAW（6984 x 4660）
- ISO: 200
- 絞り: Av14（ISO160版から変更なし）
- シャッター: 1/15秒
- 投影ディスプレイ: Win32 `DISPLAY4`、1920 x 1080
- 投影ウィンドウ位置: `(3440, 0)`
- 使用投影領域: `(x=613, y=201, width=722, height=722)`
- 初回投影待ち: 300 ms
- 2枚目以降の切替待ち: 1 ms
- 色変換行列: RGB各4段階、4³ = 64色

## 露出確認

ISO200・Av14の白色ROI測定結果:

- 平均線形RGB: `(0.758, 0.456, 0.818)`
- 最大線形RGB: `(1.000, 0.655, 1.000)`
- 0.98以上の画素: 0.802%
- 0.95以上の画素: 2.004%
- 黒色ROI平均RGB: `(0.00088, 0.00034, 0.00076)`

白色ROIの一部でR/Bが飽和するが、明るさを上げる目的とAv固定の指定を優先し、
ISO200・Av14を全工程で使用した。

参考診断としてISO200・Av16も撮影したが、本工程には使用していない。

## 実行した処理

1. ISO200・Av14で白・黒投影を実写し、線形RAWのROIを測定
2. RGB各チャンネルの実測逆LUTを構築
3. 色補償・ガンマなし用の64色校正
4. 色補償・解析ガンマ2.2用の64色校正
5. 色補償・実測逆LUT用の64色校正
6. 3画像 x 4条件 = 12枚を同一トリガバッチで撮影
7. P2Cワープ、投影領域クロップ、PSNR・SSIM・Delta E76評価

## 逆LUTの再測定

ISO200の逆LUTではGチャンネル高輝度端に不連続があった。

| G投影値 | 1回目の線形G応答 | 2回目の線形G応答 |
| ---: | ---: | ---: |
| 223 | 0.404 | 0.400 |
| 239 | 0.462 | 0.459 |
| 255 | 0.663 | 0.671 |

G=239から255で応答が約46%増える挙動が2回とも再現した。R/B漏れ成分も
同様に増えているため、単発フレームやLUT計算の失敗ではなく、
ISO200で観測された投影・撮影系の再現可能な高輝度端特性と判断した。

2回の逆LUT差はチャンネル平均で0.1～0.4%程度で、LUT自体はRGB各256点、
範囲0～1、全チャンネル単調だった。64色校正で使用した1回目のLUTを本番名に
保存し、2回目も確認用として別保存した。

この高輝度端の不連続により、ISO200では実測逆LUTより解析ガンマ2.2のほうが
安定した結果になった。EDSDKのフレーム欠落や前フレーム残りではなく、
`edsdk-python`側の修正が必要な症状は確認されなかった。

## 目視確認

12枚すべてを確認し、画像1→2、画像2→3の切替直後を含めて前フレーム残りが
ないことを確認した。

中央上部の台形状の濃淡と上端のテープは、全フレームの同一位置に現れる投影面の
物理的な段差・貼り合わせであり、残像ではない。
