# EPSON プロジェクタ切替後の全再校正と特性計測 — 2026-08-17

プロジェクタを EPSON PJ に交換した後の、色補償フルパイプライン（Tv1/60×5ISO + Tv1/30×4ISO）と
特性計測・図一式の再取得。旧プロジェクタの記録は
[`docs/color_grid_response_20260812.md`](color_grid_response_20260812.md)（§7まで）。

## 1. セットアップ（実測で確定した事項）

- **投影位置**: `\\.\DISPLAY4` = (3440,0) 1920×1080 @60Hz（赤/黒プローブで確認。
  Tv=1/60 は 60Hz の1周期でフリッカーフリー。位相ジッタ 3.3% は既知の代償）
- **露出**: Tv=1/60・av=14 固定（ユーザー指示: Tv=1/60、絞りは元のf/14で
  フォーカス不変）。EPSON は旧機より大幅に明るく、
  - av14・Tv1/15 では投影面右下 約5% がセンサ飽和（切替直後に発見）
  - Tv1/60・av14 では **ISO320以上で LUT ROI の5割が飽和** → クリーン上限は ISO250
  - 採用スイープ: **ISO 100 / 200 / 250**（白 LUT-ROI 0.137 / 0.272 / 0.344、全て飽和ゼロ）
- **固定ROI**: ISO200 の全画面 GrayCode から導出した (324,48,922,922)(inset8) を
  inset24 相当に縮めた **(340,64,890,890)**。ユーザー指示によりROIは最初の決定を
  全ランで固定、GrayCode/p2c は ISO ごとに再取得（対応点 911万〜1032万、外挿 0.7%）
- WB=ColorTemp(D65) 維持。config: `config.epson_iso{100,200,250}_nonhdr_20260817.toml`

## 2. 色補償キャンペーン（5条件 × 5 ISO、リニア統一・tdnone）

初回スイープは飽和回避で 100/200/250。2026-08-18 未明にユーザー指示で
**飽和許容の 320/400 を追加**（白で LUT ROI の約5割が飽和する条件）。

| 条件 | ISO100 | ISO200 | ISO250 | ISO320 | **ISO400** |
| --- | --- | --- | --- | --- | --- |
| no_comp | 7.14 / 51.5 | 8.07 / 46.3 | 8.57 / 43.6 | 10.27 / 35.4 | 10.93 / 32.7 |
| comp_no_gamma | 8.84 / 38.7 | 11.47 / 26.1 | 13.42 / 20.9 | 16.74 / 16.8 | 16.09 / 17.0 |
| comp_gamma | 8.83 / 38.9 | 11.52 / 25.5 | 13.44 / 20.3 | **17.02 / 13.05** | **17.48 / 11.76** |
| comp_inverse_lut | 8.84 / 38.9 | 11.51 / 25.5 | 13.47 / 20.0 | 16.93 / 14.0 | 17.48 / 11.85 |
| comp_inverse_lut_gray | 8.84 / 38.9 | 11.51 / 25.5 | 13.45 / 20.9 | 16.53 / 15.2 | 17.45 / 12.3 |

（各セル: PSNR[dB] / ΔE76）

- **総合最良は ISO400 の comp_gamma / comp_inverse_lut = 17.48dB / ΔE11.8 /
  SSIM 0.743** — 白の部分飽和（ROI約5割）のペナルティより採点レンジ拡大の
  利得が大きい。実画像は真っ白に近い画素が少ないため飽和の実害が限定的
- クリーン域（100〜250）では **4方式が0.05dB以内に一致**（EPSONの加法性・
  γ2.2一致の帰結）。**飽和域（320/400）では方式差が復活**する — 飽和が各
  線形化の白端 fit を別々に歪めるためで、comp_no_gamma だけ明確に劣化する
- ΔE 11.8 は旧機最良（ΔE14.6, ISO400非HDR 1/15）を上回る

## 2b. Tv=1/30 スイープ（2026-08-18、ユーザー指示: ISO250〜500）

| comp_gamma | ISO250 | ISO320 | ISO400 | ISO500 |
| --- | --- | --- | --- | --- |
| PSNR / SSIM / ΔE | **18.60 / 0.761 / 9.86** | 20.01 / 0.774 / 13.4 | 20.26 / 0.760 / 13.1 | 18.39 / 0.732 / 18.7 |

- **全実験を通じた最良 = Tv1/30・ISO250・comp_gamma（ΔE 9.86、初の一桁）**。
  判定基準はΔE（色再現）。PSNR最良は ISO400@1/30 (20.26)
- ISO500 で補償利得がほぼ消失（no_comp ΔE20.3 → comp 16.8〜18.7）— 飽和進行で
  改善カーブが転落。白ROI飽和率は 250〜500 で 54〜56% と同水準だが、飽和「深さ」が
  増えるほど校正 fit の歪みが勝る
- 明るくするほど PSNR/SSIM は上がり続けたが（320/400）、ΔEは ISO250 が明確に最良 —
  輝度・構造と色の最適点が分かれる

## 3. 特性計測（ISO250、216色校正 + 321色応答 + 3D LUT 検証）

旧プロジェクタ（2026-08-12/13, ISO200 HDR D65）との比較:

| 指標 | 旧プロジェクタ | **EPSON** |
| --- | --- | --- |
| 白応答バランス (R,G,B) | (0.57, 0.31, 0.42) 強マゼンタ | **(0.32, 0.32, 0.29) ほぼ中立** |
| 番兵ドリフト | ±0.9〜5.2%（アイリス過渡あり） | **≤0.94%（補正不要）** |
| 加法比 mix/sum (R/G/B) | 1.25 / 0.81 / 0.80 | **0.91 / 0.96 / 1.07** |
| 白 vs 原色和（最悪水準） | R@51 = **2.70** | B@51 = 1.29 |
| G→R クロストーク | 32% | ほぼ消失（応答ファミリー参照） |
| CV: ガンマ2.2+行列 ΔE | 13.4 | **4.2** |
| CV: 1D LUT+行列 ΔE | 15.2〜19.1 | 5.1〜5.6 |
| CV: TPS 3D ΔE | 3.3 | **0.97** |
| 3D LUT実機: gray / held-out ΔE | 4.2 / 4.5 | **1.8 / 1.8** |
| 到達殻の形 | せん断された塊（G1.35/R0.67） | **ほぼ直方体（加法的平行六面体）** |

要点:

1. **EPSON はほぼ加法的・γ2.2一致・チャンネル整合**（channel_ramp LUT ≈ gray LUT、
   L(0.5)=185〜189 ≈ γ2.2 理論値186）。ADICT が LCD 系に見た「素直なデバイス」で、
   旧機（白セグメント型DLP挙動）の対極
2. 古典パイプライン（1D+行列）の構造誤差は ΔE 13〜19 → **4〜5** に縮小。
   TPS/3D LUT なら **ΔE ≈ 1**（実機 held-out 1.8）まで到達
3. 単チャンネル要求（c=0成分）の ΔE 15.3 は到達殻の外（色域）の問題で、
   デバイス改善後も残る（純色は依然この機でも殻の外）
4. 補償の律速は今や**露出制約（採点レンジ）と色域**であり、モデルではない

## 5. 経緯メモ（切替当日のトラブルと対処）

- av14/Tv1/15 で面内5%飽和を発見 → av16 化 → **ISO200でROIの54%飽和を発見**
  （「ISO不変」に見えたのは全ISO部分飽和の見かけ。実際は ISO×露光に比例）→
  Tv1/60指示 → av補償案（ISO毎に絞り変更）→ **フォーカス不変のためav14固定の指示**
  → ISOクリーン上限の実測（320以上不可）→ ISO100/200/250 で確定
- 評価スクリプトへの comp ディレクトリ指定ミス（`compensation_projector/`
  サブディレクトリが必要）で ISO200 評価が一度失敗 → ドライバ修正して再実行
- 中断時に EDSDK ワーカーがカメラを掴んだまま残る事象2回 → プロセス整理で復旧
