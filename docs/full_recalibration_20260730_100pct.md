# DISPLAY4 100%設定後の色補償フル再校正（2026-07-30）

> この文書はISO200解析ガンマだけを再校正した時点の履歴である。
> その後、ISO200/400の5条件比較まで追加実施した。現行結果は
> `docs/iso200_iso400_five_condition_comparison_20260730.md`を参照。

## 結論

DISPLAY4のWindows表示スケーリングを100%へ変更した状態で、幾何確認、
4段階グレー撮影、64色の解析逆ガンマ方式校正、補償なし／ありの実投影比較を
すべて新規撮影から実行した。カメラはISO200、Av14、1/15秒、フル解像度RAWで、
半解像度RAWは使用していない。

3画像平均では、補償によりPSNRが15.76から19.51 dB、SSIMが0.7890から
0.7931、Delta E76が26.50から14.60へ改善した。紫かぶりは目視でも大きく
減った。一方で白投影のR/B飽和が強く、補償後に緑・黄方向の過補償が残る。
今回の結果を「完全に正しい色再現」とは評価しない。

## 実行条件

- DISPLAY4: Windows論理・物理とも1920 x 1080、スケーリング100%
- ウィンドウ位置: `(3440, 0)`
- 有効投影領域: `(613, 201, 722, 722)`
- カメラ: Canon EDSDK、ISO200、Av14、1/15秒、LR
- RAW現像: 4660 x 6984、`half_size=false`
- 解析逆ガンマ: 2.2
- 色校正パターン: RGB各4段階、合計64色
- 幾何: `data/graycode_recalibration_20260730/p2c_dense_active_1920x1080.npy`

## 100%変更後の幾何確認

チェッカーを新規投影・撮影し、既存dense P2Cを再検証した。

| 指標 | dense P2C |
| --- | ---: |
| 位相差x | -0.253 px |
| 位相差y | -0.168 px |
| inner相関 | 0.9531 |
| RMSE | 0.2346 |
| ワープ時間 | 0.128秒 |

残差は1 px未満であり、100%変更後もP2Cは有効だった。このためGrayCode自体は
再撮影せず、このマップを色行列ワープへ使用した。

## 4段階グレーと白投影

生のプロジェクタコード`0, 85, 170, 255`を黒から白の順で1バッチ撮影した。
投影・撮影・フルRAW現像は合計17.24秒。確認ROIはカメラ座標
`(4520, 1600, 480, 400)`。

| 投影コード | ROI平均linear RGB | 全ch平均 | 0.98以上を含む画素 |
| ---: | --- | ---: | ---: |
| 0 | (0.00085, 0.00033, 0.00074) | 0.00064 | 0.0% |
| 85 | (0.06736, 0.04139, 0.07080) | 0.05984 | 0.0% |
| 170 | (0.31279, 0.18910, 0.32849) | 0.27679 | 0.0% |
| 255 | (0.90109, 0.55736, 0.96924) | 0.80922 | 55.4% |

平均応答は4段階で厳密に単調増加した。白では最大R/Bが1.0へ達し、
R/Bを中心に強く飽和している。現行64色fitは飽和画素を除外しないため、
この露出条件は行列推定上の明確な制約になる。

目視用4面画像:

`data/full_recalibration_20260730_100pct/grayscale_4level/grayscale_4level_contact_sheet.png`

## 64色の新規校正

既存行列は読み込まず、64パターンを新規投影・撮影して全画素行列をfitした。

| 工程 | 時間 |
| --- | ---: |
| 投影・トリガ撮影 | 153.61秒 |
| 後段フルRAW現像 | 103.72秒 |
| パターン生成から補償画像保存まで | 約549.8秒 |

- 撮影PNG: 64枚
- 行列形状: `(4660, 6984, 4, 3)`、float32、約1.45 GiB
- 行列SHA256:
  `CC0BC9F0332E72298D97EC5B9DC964897998BC4C7F51527467CD2075EF572D71`
- 生成した解析逆ガンマ補償画像: 3枚

撮影順の診断では、隣接する64フレームのROI RGB距離の最小値は15.71コードで、
1コード未満の同一隣接フレームは0組だった。入力と同一チャンネル応答の相関は
R=0.904、G=0.992、B=0.973。前フレームがそのまま残った証拠はない。

ただしこれはパターンIDを画像へ埋め込んだ完全な同定ではなく、応答順序と
目視画像による検査である。

## 補償なし／新規補償ありの実投影結果

3ターゲット x 2条件の6枚を同一トリガバッチで新規撮影した。
投影・トリガ14.51秒、後段RAW現像10.72秒、API全体26.23秒。

| 画像 | 条件 | PSNR [dB] | SSIM | Delta E76 |
| --- | --- | ---: | ---: | ---: |
| nature_1 | 補償なし | 15.10 | 0.7801 | 24.68 |
| nature_1 | 新規補償あり | 17.41 | 0.7807 | 18.12 |
| nature_2 | 補償なし | 16.36 | 0.7715 | 26.53 |
| nature_2 | 新規補償あり | 20.92 | 0.7829 | 10.73 |
| nature_3 | 補償なし | 15.82 | 0.8153 | 28.27 |
| nature_3 | 新規補償あり | 20.19 | 0.8156 | 14.94 |
| **3画像平均** | **補償なし** | **15.76** | **0.7890** | **26.50** |
| **3画像平均** | **新規補償あり** | **19.51** | **0.7931** | **14.60** |

平均差:

- PSNR: +3.74 dB
- SSIM: +0.0041
- Delta E76: -11.90

全3画像でPSNRとDelta E76が改善した。目視では補償なしの紫かぶりが減り、
明るさもターゲットへ近づいた。一方、補償後は緑・黄が強い箇所があり、
投影面中央上部の物理的な貼り合わせ・段差も残る。

最終投影画像では、active領域内で1チャンネル以上が255の画素率が画像ごとに
36.6%、18.5%、24.3%だった。再現範囲外をclipしている割合が小さくなく、
白飽和と合わせて、残る色誤差の一因である。
