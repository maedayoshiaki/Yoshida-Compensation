# ISO160での色補償・ガンマ・逆LUT実機比較（2026-07-29）

## 結論

色補償に使う撮影設定を ISO100 から ISO160 へ上げ、露出確認、逆LUT測定、
3種類の64色校正、4条件の比較撮影をすべて最初からやり直した。

ISO160・Av13・1/15秒では白色ROIの46.46%が0.98以上になり飽和したため、
最終設定は **ISO160・Av14・1/15秒** とした。この設定の実効露光量は旧設定
ISO100・Av13・1/15秒の約1.38倍で、白色ROIには0.95以上の画素がなかった。

4条件の平均では、実測逆LUTがPSNRとDelta E76で最良、解析ガンマ2.2がSSIMで
わずかに最良だった。ISO100時と比べると、実測逆LUTのPSNRは1.22 dB向上し、
Delta E76は1.58低下した。

| 条件（3画像平均） | PSNR [dB] | SSIM | Delta E76 |
| --- | ---: | ---: | ---: |
| 色補償なし | 13.37 | 0.389 | 28.87 |
| 色補償あり・ガンマ補正なし | 15.97 | 0.4071 | 19.90 |
| 色補償あり・解析ガンマ2.2 | 16.72 | **0.4072** | 17.84 |
| **色補償あり・実測逆LUT** | **16.75** | 0.4066 | **17.75** |

## 撮影条件

- カメラ: Canon EDSDK、フル解像度RAW（6984 x 4660）
- ISO: 160
- 絞り: Av14
- シャッター: 1/15秒
- 投影ディスプレイ: Win32 `DISPLAY4`、1920 x 1080
- 投影ウィンドウ位置: `(3440, 0)`
- 使用投影領域: `(x=613, y=201, width=722, height=722)`
- P2Cマップ: `data/hardware_recalibration_20260729/maps/p2c_homography_1920x1080.npy`
- 初回投影待ち: 300 ms
- 2枚目以降の切替待ち: 1 ms

### 露出の選定

| 候補 | 白色ROI平均RGB | 0.98以上の画素 | 判定 |
| --- | --- | ---: | --- |
| ISO160・Av13 | (0.901, 0.559, 0.951) | 46.46% | 飽和のため不採用 |
| **ISO160・Av14** | **(0.600, 0.368, 0.636)** | **0%** | **採用** |

ISO160・Av14では白色ROIの最大RGBも `(0.866, 0.506, 0.888)` に収まり、
0.95以上の画素は0%だった。投影領域全体の0.98以上の画素率は
0.00018%で、端部のごく少数だけだった。

## やり直した処理

1. ISO160候補の白・黒テスト撮影と飽和検査
2. ISO160・Av14でRGB各チャンネルの逆LUTを再測定
3. 色補償あり・ガンマ補正なし用の4段階RGB校正（4³ = 64色）
4. 色補償あり・解析ガンマ2.2用の4段階RGB校正（64色）
5. 色補償あり・実測逆LUT用の4段階RGB校正（64色）
6. 3対象画像 x 4条件 = 12枚を同一トリガバッチで実写比較
7. P2Cワープ、投影領域クロップ、PSNR・SSIM・Delta E76評価

3つの補償方式はそれぞれ独立した64色撮影と色変換行列を使用している。

旧ISO100処理と比較すると、逆LUT測定は337.4秒から約321秒へ16秒短縮した。
64色処理は方式により約560～590秒で、トリガ撮影部分は約153～165秒だった。
投影を先に連続実行し、RAW現像を後段へまとめる方式を全工程で使用した。

## ISO100からの変化

| 条件 | PSNR差 [dB] | SSIM差 | Delta E76差 |
| --- | ---: | ---: | ---: |
| 色補償なし | +1.24 | +0.0229 | -2.29 |
| 補償・ガンマなし | +1.02 | +0.0009 | -1.31 |
| 補償・解析ガンマ | +1.14 | +0.0034 | -1.34 |
| 補償・逆LUT | +1.22 | -0.0000 | -1.58 |

明るさを上げたことで全条件のPSNRとDelta E76が改善した。補償方式間では、
解析ガンマと実測逆LUTは近いが、今回の平均では実測逆LUTがわずかに優位だった。

## 目視確認

12枚すべてを確認し、各条件が正しい対象画像を撮影していることを確認した。
特に画像1から画像2、画像2から画像3への切替直後にも前フレームは残っていない。

中央上部の台形状の濃淡と上端のテープは、全フレームの同一位置に現れる投影面の
物理的な段差・貼り合わせであり、投影切替の残像ではない。
