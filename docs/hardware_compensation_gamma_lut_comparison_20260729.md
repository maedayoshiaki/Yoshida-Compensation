# 色補償・ガンマ・逆LUTの4条件実機比較（2026-07-29）

## 結論

指定された次の4条件を、同じ物理セットアップ、露出、P2Cマップ、
トリガバッチで実写比較した。

1. 色補償なし
2. 色補償あり・ガンマ補正なし
3. 色補償あり・解析的ガンマ補正あり（gamma=2.2）
4. 色補償あり・実測逆LUT

色補償を行う3条件は、投影系が異なるため、それぞれ専用のRGB各4段階、
合計64色の色変換行列を実写から作成した。

| 条件（3枚平均） | PSNR [dB] | SSIM | Delta E76 |
| --- | ---: | ---: | ---: |
| 色補償なし | 12.13 | 0.367 | 31.17 |
| 色補償あり・ガンマなし | 14.95 | 0.406 | 21.21 |
| **色補償あり・ガンマ2.2** | **15.58** | 0.404 | **19.18** |
| 色補償あり・実測逆LUT | 15.53 | **0.407** | 19.33 |

解析ガンマと逆LUTは僅差だった。解析ガンマは平均PSNRとDelta E76、
逆LUTは平均SSIMが最良だった。

色補償なしに対し、解析ガンマ併用はPSNRが3.44 dB改善し、
Delta E76が11.99低下した。逆LUT併用はPSNRが3.39 dB、
SSIMが0.040改善し、Delta E76が11.84低下した。

## 条件の作り方

### 色補償なし

元のsRGB目標画像をactive regionへ配置してそのまま投影した。

### 色補償あり・ガンマ補正なし

RGB各4段階のリニア値をそのまま投影した64色から色変換行列を計算した。
生成した線形補償画像にもガンマ変換を加えず投影した。

### 色補償あり・解析的ガンマ補正

64色の校正パターンへ`x^(1/2.2)`を適用して撮影し、専用行列を計算した。
最終補償画像にも同じ解析的逆ガンマを適用した。

### 色補償あり・実測逆LUT

現在の投影面右側にある均一な白色ROIでRGB別逆LUTを測定した。
64色の校正パターンと最終補償画像の両方へ同じ逆LUTを適用した。

## 4段階色変換行列

3方式すべてでRGB各4値の直積64色をフル解像度RAWで撮影し、
全32,545,440カメラ画素について4×3行列を最小二乗計算した。

| 色補償方式 | 投影・撮影 | RAW現像 | 全体 |
| --- | ---: | ---: | ---: |
| ガンマなし | 152.39秒 | 112.65秒 | 590.0秒 |
| 解析ガンマ2.2 | 153.01秒 | 105.98秒 | 558.9秒 |
| 実測逆LUT | 152.40秒 | 112.78秒 | 653.6秒 |

各方式について、全64枚の投影パターン、実写PNG、1.56 GBの色変換行列、
線形補償画像、実投影用補償画像を別々に保存した。

最終4条件比較は12枚を同一トリガバッチで撮影し、投影・撮影28.93秒、
後段RAW現像18.84秒、撮影開始から現像完了まで48.82秒だった。

## 実測逆LUT

測定ROIは中央の黒い物体や色紙を避けた白色面
`(camera x=4520, y=1600, width=480, height=400)`とした。

- sampling: `channel_ramp`
- 17階調×RGB（重複黒を除く49パターン）
- HDRを含む実撮影: 134露光
- LUT解像度: RGB各256点
- 全RGBチャンネルで単調性を確認
- 構築時間: 337.4秒

| 目標出力 | R入力 | G入力 | B入力 |
| ---: | ---: | ---: | ---: |
| 0.25 | 0.466 | 0.509 | 0.417 |
| 0.50 | 0.779 | 0.712 | 0.632 |
| 0.75 | 0.906 | 0.866 | 0.789 |
