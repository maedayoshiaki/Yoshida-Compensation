# ISO200/400・5条件色補償比較（2026-07-30）

## 結論

DISPLAY4を100%、Av14、1/15秒、フル解像度RAW、RGB各4段階の条件で、
ISO200とISO400の両方について次の5条件を実写比較した。

1. 色補償なし
2. 色補償あり・ガンマなし
3. 色補償あり・解析逆ガンマ2.2
4. 色補償あり・RGB単独チャンネルランプ逆LUT
5. 色補償あり・グレー投影fit逆LUT

各補償方式は同じ行列を使い回さず、各ISO・各方式について64色を別々に
投影・撮影して専用行列をfitした。

- ISO200では解析逆ガンマが平均3指標すべてで最良。
- ISO200のグレー逆LUTはチャンネル逆LUTより全平均指標が改善。
- ISO400ではチャンネル逆LUTが補償方式中のPSNR・SSIM最高。
- ISO400では解析逆ガンマがDelta E76最小。
- ISO400のグレー逆LUTは解析ガンマ・チャンネル逆LUTの両方より悪化。
- ISO400の白投影は確認ROIの99.998%が0.98以上で、ほぼ全面飽和。

## 共通条件

- DISPLAY4: 1920 x 1080、Windows表示スケーリング100%
- OpenCVウィンドウ位置: `(3440, 0)`
- active領域: `(613, 201, 722, 722)`
- Av: 14
- Tv: 1/15秒
- RAW: 4660 x 6984、`half_size=false`
- 色行列: RGB各4段階、4³=64色
- 解析ガンマ: 2.2
- 幾何: dense P2C
  `data/graycode_recalibration_20260730/p2c_dense_active_1920x1080.npy`

ISO400はISO200から1 stopだけ上げた。通常の64色色行列校正と最終比較では、
ISO以外の設定を変更していない。

逆LUT測定だけは既存のHDR仕様に従い、基準1/15秒から飽和時は短く、
暗部では長くした。これはLUT測定用のブラケットであり、64色色行列撮影の
露出は1/15秒固定である。

## 白・4段階グレーの露出

| ISO | 投影コード | ROI全ch平均linear | 0.98以上を含む画素 |
| ---: | ---: | ---: | ---: |
| 200 | 0 | 0.00064 | 0.0% |
| 200 | 85 | 0.05984 | 0.0% |
| 200 | 170 | 0.27679 | 0.0% |

| 400 | 0 | 0.00115 | 0.0% |

| 400 | 170 | 0.77554 | 17.4% |
| 400 | 255 | 0.99998 | 99.998% |

ISO400ではコード170からR/B飽和が始まり、白ではR/G/Bがほぼ完全に飽和した。
現行の64色行列fitは飽和画素を除外しない。このためISO400の結果には、
ISOを上げた明るさと同時に、fit情報の欠損も含まれる。

## 逆LUTの測定方法

### チャンネルランプ

各チャンネルを単独で17段階投影する。

```text
(v,0,0), (0,v,0), (0,0,v)
```

黒の重複をまとめ、base exposureは49ユニークパターン。

- ISO200: HDR込み128撮影
- ISO400: HDR込み131撮影

投影したチャンネル自身の応答だけを各LUTへ使う。

### グレー投影fit

17段階の`(v,v,v)`を投影し、同じ撮影のR/G/B応答をそれぞれのLUTへ使う。

- ISO200: HDR込み49撮影
- ISO400: HDR込み50撮影
- ISO400では白飽和回復に1/30秒と1/60秒も使用

どちらもRGB別256点の1D LUTであり、3D LUTではない。

`desired_response=1`での最終プロジェクタ入力値:

| ISO | LUT source | R | G | B |
| ---: | --- | ---: | ---: | ---: |
| 200 | channel_ramp | 1.000 | 1.000 | 1.000 |
| 200 | gray | 0.938 | 0.938 | 0.938 |
| 400 | channel_ramp | 0.813 | 0.876 | 0.751 |
| 400 | gray | 0.688 | 0.876 | 0.751 |

fitの前向き曲線には`input=1 -> response=1`アンカーを入れるが、信頼範囲内の
最大応答が入力1より前に正規化白へ達すると、反転後のLUT終端は1未満になる。

## ISO200の5条件結果

3画像平均:

| 条件 | PSNR [dB] | SSIM | Delta E76 |
| --- | ---: | ---: | ---: |
| 補償なし | 15.72 | 0.7884 | 26.72 |
| 補償・ガンマなし | 18.29 | 0.7491 | 16.87 |
| **補償・解析逆ガンマ** | **19.77** | **0.7956** | **13.53** |
| 補償・チャンネル逆LUT | 19.34 | 0.7810 | 15.97 |
| 補償・グレー逆LUT | 19.50 | 0.7941 | 14.60 |

解析逆ガンマが平均3指標すべてで最良だった。グレー逆LUTはチャンネル逆LUTに
対してPSNR +0.16 dB、SSIM +0.0131、Delta E76 -1.37となった。

15枚の最終比較は、投影・撮影・後段RAW現像API全体で63.10秒。

## ISO400の5条件結果

3画像平均:

| 条件 | PSNR [dB] | SSIM | Delta E76 |
| --- | ---: | ---: | ---: |
| 補償なし | 20.03 | **0.8426** | 23.60 |
| 補償・ガンマなし | 19.96 | 0.7453 | 15.92 |
| 補償・解析逆ガンマ | 22.94 | 0.7917 | **13.77** |
| 補償・チャンネル逆LUT | **23.29** | 0.8216 | 14.49 |
| 補償・グレー逆LUT | 21.00 | 0.7668 | 17.83 |

全5条件中のSSIM最高は補償なしだった。補償方式内ではチャンネル逆LUTが
PSNR・SSIM最高、解析逆ガンマがDelta E76最小であり、指標をまたぐ単一の
最良方式はない。

グレー逆LUTはチャンネル逆LUTに対してPSNR -2.29 dB、SSIM -0.0547、
Delta E76 +3.34となった。目視でも黄・赤方向への偏りが強い。

考えられる要因は、ISO400でグレー高輝度応答が強く飽和し、RGB同時投影時の
クロストークを含む応答をRGB別1D曲線へ分解していること。ただしこれは実測に
基づく推定であり、原因を一意に分離できたわけではない。

15枚の最終比較は、投影・撮影・後段RAW現像API全体で63.30秒。

ルート`data/color_mixing_matrices.npy`は、現行既定であるISO400解析逆ガンマの

残してはいない。

## 実装変更

`sample_inverse_lut.py`へ次を追加した。

- `--lut-pattern-dir`
- `--lut-comp-dir`

これにより方式ごとの投影パターン・最終画像を別ディレクトリへ保存でき、
以前の固定`data/inv_lut_*`による上書きを回避した。

`evaluate_compensation_conditions.py`へ任意の
`--gray-lut-comp-dir`を追加した。未指定なら従来の4条件、指定時は
グレー逆LUTを加えた5条件を同一トリガバッチで評価する。

## 評価上の注意

- 指標はカメラ・rawpy・sRGB仮定を含む画像ベース評価で、測色器評価ではない。
- ISOを変えると評価カメラ自体の露出も変わるため、ISO200と400の数値差は
  プロジェクタ補償だけの差ではない。
- 補償なしのSSIMが高くても、色差が小さいことを意味しない。
- 64色色行列fitは飽和除外・繰返し平均・ロバスト回帰を行わない。
- active領域中央上部の貼り合わせ・段差は物理的な投影面であり、補償だけでは消えない。
