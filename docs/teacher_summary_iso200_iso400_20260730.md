# 投影色補償におけるISO200・ISO400の比較

実験日: 2026年7月30日

## 1. 目的

プロジェクタ投影時の色ずれを補正する色補償について、カメラ感度を
ISO200からISO400へ1段上げた場合の影響を比較した。

また、プロジェクタの非線形な明るさ応答を扱う方法として、次の5条件を評価した。

1. 色補償なし
2. 色補償あり・ガンマ補正なし
3. 色補償あり・解析逆ガンマ（γ=2.2）
4. 色補償あり・RGBチャンネル別の実測逆LUT
5. 色補償あり・グレー投影から推定した実測逆LUT

## 2. 実験条件

| 項目 | 設定 |
| --- | --- |
| プロジェクタ解像度 | 1920 × 1080 |
| 使用投影領域 | 722 × 722 |
| カメラ感度 | ISO200 / ISO400 |
| 絞り | Av14 |
| シャッター速度 | 1/15秒 |
| 撮影形式 | フル解像度RAW（6984 × 4660） |
| 幾何補正 | GrayCodeによるdense P2C対応 |
| 色校正 | RGB各4段階、合計64色 |
| 評価画像 | 自然画像3枚 |

各ISO・各補償方式について64色を個別に撮影し、方式専用の色変換行列を推定した。
異なる方式間で同じ行列は使い回していない。

## 3. 評価結果

PSNR・SSIMは大きいほど、Delta E76は小さいほど良い。
表は自然画像3枚の平均値である。

### ISO200

| 条件 | PSNR ↑ | SSIM ↑ | Delta E76 ↓ |
| --- | ---: | ---: | ---: |
| 補償なし | 15.72 | 0.7884 | 26.72 |
| ガンマ補正なし | 18.29 | 0.7491 | 16.87 |
| **解析逆ガンマ** | **19.77** | **0.7956** | **13.53** |
| RGBチャンネル逆LUT | 19.34 | 0.7810 | 15.97 |
| グレー投影逆LUT | 19.50 | 0.7941 | 14.60 |

ISO200では、解析逆ガンマ方式が3指標すべてで最良だった。
グレー投影逆LUTは、RGBチャンネル逆LUTより良好な結果となった。

### ISO400

| 条件 | PSNR ↑ | SSIM ↑ | Delta E76 ↓ |
| --- | ---: | ---: | ---: |
| 補償なし | 20.03 | **0.8426** | 23.60 |
| ガンマ補正なし | 19.96 | 0.7453 | 15.92 |
| 解析逆ガンマ | 22.94 | 0.7917 | **13.77** |
| **RGBチャンネル逆LUT** | **23.29** | 0.8216 | 14.49 |
| グレー投影逆LUT | 21.00 | 0.7668 | 17.83 |

ISO400では、RGBチャンネル逆LUTが補償方式中のPSNR・SSIMで最良だった。
色差は解析逆ガンマ方式が最小だった。

一方、グレー投影逆LUTはISO200と異なり、解析逆ガンマおよび
RGBチャンネル逆LUTより悪い結果となった。

## 5. ISOを上げた影響

ISO400では撮影画像が明るくなり、PSNRは全体として向上した。
ただし、白投影時の飽和が大幅に増加した。

| ISO | 白投影で0.98以上となったROI画素 |
| ---: | ---: |
| 200 | 55.4% |
| 400 | 99.998% |

ISO400では、白投影がほぼ全面飽和した。さらに、投影コード170の段階でも
17.4%の画素で飽和が発生した。

現在の色変換行列推定では飽和画素を除外していないため、ISO400では
高輝度側の情報が失われ、色変換精度を制限している可能性がある。

## 6. まとめ

- 色補償により、両ISOでDelta E76が大きく改善した。
- ISO200では解析逆ガンマ方式が最も安定して良好だった。
- ISO400ではRGBチャンネル逆LUTのPSNRが最高だったが、
  色差は解析逆ガンマ方式のほうが小さかった。
- グレー投影逆LUTはISO200では有効だったが、ISO400では悪化した。
- ISO400は明るさの点では有利だが、白および高輝度色の飽和が非常に大きい。

以上から、現状の撮影条件では、色再現精度と安定性を優先する場合は
**ISO200・解析逆ガンマ方式**が最も扱いやすい。

ISO400を使用する場合は、露出を別途調整するか、色変換行列の推定時に
飽和画素を除外する処理を追加する必要がある。

## 7. 注意事項

- 評価は測色器ではなく、RAW撮影画像を用いた画像ベース評価である。
- ISOを変更すると評価用カメラ画像の明るさも変わるため、
  ISO間の数値差はプロジェクタ補償だけの差ではない。
- 投影面の貼り合わせや段差による局所的な濃淡は、色補償だけでは除去できない。
- 逆LUTはRGB別の1次元LUTであり、RGB間の相互作用を直接表す3D LUTではない。
