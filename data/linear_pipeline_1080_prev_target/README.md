# 完全リニア色補償パイプライン (1920x1080, 2026-07-24)

ユーザー指示による最終構成。**全工程リニア**：

- プロジェクタ：常に channel_ramp 測定LUT（`data/inverse_lut.npz`, trust_low=5）で線形化
- カメラ：リニアRAW現像のまま処理（sRGBエンコードは表示/保存用のみ、フィット・補償計算には不使用）
- 行列：リニアパターン値 ↔ リニア撮影値（p2cワープ済み）でフィット
- ターゲット：sRGB画像 → リニアにデコードしてから補償計算
- 解像度：1920x1080（このセッション中にディスプレイが 1280x720 → 1920x1080@60 に変更されたため再校正）

## ワークフロー

1. GrayCode 幾何校正 @1920x1080（`graycode_run.py`、結果はリポジトリルートの `result_*_delaunay.npy`）
2. 27色グリッドパターンを LUT 線形化して投影・リニア撮影・p2cワープ → 画素ごと 4x3 アフィン行列をリニア空間でフィット
3. 512x512 正方形ターゲットを投影領域 **(x=613, y=201, 一辺=722)**（デコード済みキャンバスの最大内接正方形−8px）へ補償投影
4. 撮影（リニア）→ p2cワープ → 領域crop → 512x512 リサイズ → 評価

## 結果（3枚平均）

| 条件 | PSNR(sRGB) [dB] | SSIM(sRGB) | ΔE76 |
|---|---|---|---|
| **lut_ch（本命）** | **19.57** | 0.791 | **14.85** |
| gamma 2.2（参照） | 19.56 | 0.798 | 15.44 |

旧構成（sRGBフィット/720p/領域468px）の最良 18.13dB から **+1.4dB 改善**。SSIM は 0.48-0.61 → 0.75-0.84 へ大幅改善。要因はリニア撮影（フィットデータの8bit sRGB量子化を排除）、1080p の高精細マップ・行列、投影領域の拡大（512→722 の拡大投影でリサンプリング損失減）。nature_1（霧の空）だけは色域限界（白がマゼンタ化）で 16.5dB に留まる。

## ファイル

- `matrices_linear_lut_ch.npy` / `matrices_linear_gamma.npy` — リニア空間フィット行列（1080x1920x4x3）
- `fit_captures_linear_*.npy` — フィット用リニア撮影（float16, 27枚, p2cワープ済み）— 再フィット用
- `valid_mask.npy` / `region.json` / `square_region_preview_1080.png` — 評価マスクと投影領域
- `results/<target>/square_lut_ch.png` ほか — 512x512 結果（PNG は表示用に sRGB エンコード、`.npy` がリニア実データ）
- `metrics.json` — 全指標（リニア空間 PSNR/SSIM と sRGB空間 PSNR/SSIM/ΔE76 の両方）

## 新しいターゲットの処理

物理配置・解像度が変わらない限り再校正不要：

1. 512x512 の sRGB 画像を用意
2. リニアにデコード → 領域サイズ(722)へリサイズ → `matrices_linear_lut_ch.npy` の領域切り出しで `calc_compensation_image`
3. 1920x1080 黒フレームの (613,201) に埋め込み → `apply_inverse_lut` → (3440,0) にフルスクリーン投影
4. 撮影はリニアのまま → p2cワープ → 領域crop → 512x512（`linear_pipeline.py` の Stage 2 と同一処理）
